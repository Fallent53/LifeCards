# Roadmap

## Vertical slice — implemented
Packs, 8-minute accrual, storage cap 8, six cards per pack, species + taxa, Holo, editions, serialized supply, UNKNOWN LUCA #1/1, collection, phylogenetic tree view, Codex, fixed-price market, Wikimedia media lookup, Docker, tests and CI.

## Alpha
PostgreSQL, real accounts, versioned taxonomy import, larger card corpus, image moderation, production migrations, offers and auctions.

Implemented ahead of Alpha: tamper-evident SHA-256 pack audit chain, per-card origin-pack linkage, cancellable/relistable market listings, personal market history, and official market provenance.

## Beta
Guild expeditions, Knowledge Duel, collection mastery, biome/geography albums, notifications, anti-bot/risk engine, observability and administration/editorial tools.

## Launch
Scientific review workflow, population snapshot policy, scalable tree renderer, economy simulation at target DAU, security review, accessibility, payments/legal review if monetization is introduced, and production disaster recovery.
